# すばやさクイズ (pokemon-speed-quiz)

ポケモンの「すばやさ」種族値を比較するブラウザゲームです。お手本のポケモンより素早いのはどっちか、2択で当てて10問連続の正解数を競います。

## あそびかた

1. お手本のポケモンが1匹表示されます。各ポケモンには「振り方」(最速/準速/無振り)が付いています
2. 素早さ実数値の計算ルール: 無振り = 種族値+20 / 準速 = 種族値+52 / 最速 = (種族値+52)×1.1 の切り捨て
3. 4匹の選択肢から、お手本より実数値が高い **ただ1匹** を選びます(実数値はお手本 ±20 以内の僅差)。誰も速くないと思ったら **お手本自身** をタップ — お手本が最速の問題もあります
4. 全10問。回答すると実数値と種族値が表示され、終了後に全問の履歴を確認できます

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト (問題生成ロジックの制約検証)
npm run build    # 静的ビルド (dist/)
```

### データについて

- ポケモンの日本語名と素早さ種族値(全1025匹)は `src/data/pokedata.json` に同梱しており、**実行時に PokeAPI へのリクエストは発生しません**(PokeAPI フェアユースポリシー準拠)。
- データの更新は `npm run sync-data` の**手動実行のみ**で行います。取得元は PokeAPI が GitHub で公開している CSV データであり、API サーバーには負荷をかけません。CI 等での自動実行はしないでください。
- ポケモンの画像はリポジトリに同梱せず、実行時に [PokeAPI/sprites](https://github.com/PokeAPI/sprites) を参照しています。
